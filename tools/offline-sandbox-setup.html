PC内だけのsandbox初期設定補助

ダウンロードしたHTMLを本人のPCで開いて使います。外部通信・外部スクリプト・ログ・ブラウザ保存はありません。ボタンを押すまで生成しません。実データやStripe/Cloudflareキーを入力する欄はありません。

初回の専用sandbox設定だけに使用。既存のfingerprintや利用済みregistryを置き換えないでください。保存先は同じ商品Worker・同じAPI repoです。

ローカルファイルなら生成できます。

1. テストAPIキー原本

保存先: recalm-lab/api-cost-outcome-check → Settings → Secrets and variables → Actions → New repository secret → RECALM_TEST_API_KEY。WorkerのCREDENTIALSへ原本は貼りません。

2. 専用fingerprint

保存先: Cloudflare → recalm-api-cost-check → Settings → Variables and Secrets → Secret → FINGERPRINT_SECRET。

3. SHA256・期限入りregistry JSON

保存先:同じWorkerのSecret → CREDENTIALS。accountはsandbox-e2e-20261013、期限は実行から24時間、上限は1000。SHA256とepoch値は自動計算します。既存registryがある場合は丸ごと上書きせず担当者へ伝えてください。

4. sandbox customerの対応（非秘密）

保存先:同じWorkerの通常変数BILLING_ACCOUNTS。専用IDは準備済みで入力不要です。invoice/balance/cash balance/livemodeの最終確認待ちで、有効化は担当者の検証後だけです。

コピー後は本人が準備済みの公式設定画面へ直接貼り付けます。チャット・GitHubコード・ログへ貼りません。すべて保存するまでこのページを閉じたり再生成したりせず、最後にページ内の値を消去してください。クリップボードと公式保存先の処理はこのページと別です。

この補助はStripe/Cloudflareへ接続せず、webhookを作らず、設定を変更せず、請求・契約を開始しません。STRIPE_MODE=test、3flags=falseを維持して設定します。
