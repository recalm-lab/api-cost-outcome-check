Recalm API Cost Check

請求と実行結果の対応を、明示的なrequest IDだけで照合します。対応不明、重複疑い、失敗後のretryを区別します。HTTP 200だけでタスク成功とは判断しません。

承認済み料金は、照合処理が完了して利用記録が確定した成功call 1回あたり1円（税込）。月次後払い、50円未満は翌月繰越、解約時の未精算額50円未満は免除。利用者ごとにUTC月1,000円で停止します。同じidempotency keyと同一本文のretryは再計量しません。決済と提供導線の検証は準備中です。

機能と制約
  • 金額は整数の最小単位。例: money:USD:2 の20はUSD 0.20。通貨とcreditsを合算しません。
  • 確定請求と推定額を分け、top-upと残高を利用料から除外します。
  • 入力の根拠や成功判定は利用者の申告で、独立検証していません。詐欺、不正請求、返金権利を断定しません。
  • 最大16 KiB、請求・試行・タスク各40件。同じscopeと利用者定義の成功基準が必要です。
  • 外部モデル・有料APIを呼ばず、APIコードは入力本文を保存・ログ出力しません。
